Where do I get such a file?

Ask an AI assistant such as Claude to describe the animation for you (the prompt is in the project folder: docs/efx-prompt.md). It answers with a text in curly brackets. Save that text as a file whose name ends in .json, then choose it here. Any file name works.

Using the name of an existing animation replaces it. There is room for 16 of your own.
